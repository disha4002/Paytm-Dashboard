## Paytm-Dashboard
Developed an interactive Paytm Transaction Analysis Dashboard using Power BI to analyze transaction trends, revenue performance, customer behavior, and payment activity. 
<br>
The project involved data cleaning and transformation, data modeling, and the creation of interactive visualizations and DAX measures to generate actionable insights.
<br>
The dashboard provides a comprehensive view of total transactions, transaction value, revenue, transaction trends, payment methods, customer segments, and geographic performance. Interactive slicers and filters allow users to drill down into specific time periods, transaction categories, and customer segments, making it easier to identify trends and performance patterns.

## Business questions it answers
What age group of customers use online banking the most?
<br>
What is the total number of paytm transcations?
<br>
Distinguishing the number of successful and failed transactions.

## Tools Used
Power BI desktop, power query, data transformation, data modelling and DAX measures.
